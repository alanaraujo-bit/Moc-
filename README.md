# Mocó

Seu cantinho seguro para senhas, documentos e tudo que importa.

Mocó é um gerenciador de senhas e informações sensíveis, zero-knowledge, feito para ser
simples na superfície e poderoso quando você precisa.

- **Desktop (Windows)** — `apps/desktop` (Tauri 2 + React)
- **Núcleo** — `crates/moco-core` (Rust: criptografia, cofre, gerador, importadores)

Documentação de arquitetura e segurança: [`DECISIONS.md`](DECISIONS.md) e [`docs/`](docs/).
